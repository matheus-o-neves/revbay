# RevBay - Payment Orchestration Platform

A modern payment orchestration platform built with microservices architecture.

## Features

- Multiple payment provider support (Stripe, Celcoin)
- Microservices architecture
- TypeScript throughout
- Comprehensive test suite
- Docker containerization

## Services

- **API Gateway**: Request routing and middleware
- **Payment Orchestrator**: Core payment processing logic
- **Shared**: Common utilities and types
- **Database**: Prisma ORM with PostgreSQL

## Getting Started

```bash
npm install
npm run dev
```

## Testing

```bash
npm test
```
